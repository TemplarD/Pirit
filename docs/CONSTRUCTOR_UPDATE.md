## **ЭТАП 3: 2D Конструктор (фотовизуализация)** - 🔥 ПРИОРИТЕТ

**Заменяет:** Этап 3 "3D Конструктор (базовая версия)"

**Статус:** 🔥 В работе

**Срок:** 3-4 недели

### Описание

Реализация конструктора гриндеров с 2D визуализацией на основе сменяемых фотографий/изображений вместо 3D моделей.

### Преимущества подхода

- ✅ Быстрее в реализации (3-4 недели vs 8-9 недель)
- ✅ Не требует 3D-моделлера
- ✅ Работает на всех устройствах (включая слабые)
- ✅ Проще в поддержке и обновлении
- ✅ Достаточно для старта проекта

### Технические требования

```typescript
// Интерфейсы для 2D конструктора
interface Component2D {
  id: string;
  nodeId: string;
  name: string;
  price: number;
  
  // Изображения для разных ракурсов
  images: {
    front: string;    // Вид спереди
    side: string;     // Вид сбоку
    top: string;      // Вид сверху
  };
  
  // Позиция и размер на холсте
  position: { x: number; y: number };
  size: { width: number; height: number };
  zIndex: number;     // Порядок наложения слоёв
}

interface Canvas2D {
  currentView: 'front' | 'side' | 'top';
  zoom: number;
  pan: { x: number; y: number };
  layers: Component2D[];
}
```

### Структура файлов

```
frontend/src/components/constructor2d/
├── Constructor2D.tsx          # Основной компонент
├── Canvas2D.tsx               # 2D холст с изображениями
├── ComponentPanel.tsx         # Панель выбора компонентов
├── ViewControls.tsx           # Кнопки ракурсов
├── ZoomControls.tsx           # Зум и панорамирование
├── PriceDisplay.tsx           # Отображение цены
├── LayerManager.tsx           # Управление слоями
└── types.ts                   # TypeScript типы
```

### Критерии завершения

- [ ] 2D сцена загружается и работает
- [ ] Изображения компонентов отображаются послойно
- [ ] Можно выбрать компонент и увидеть изменения
- [ ] Переключение ракурсов работает (спереди/сбоку/сверху)
- [ ] Зум и панорамирование работают
- [ ] Цена обновляется при изменении конфигурации
- [ ] Конфигурация сохраняется в JSON
- [ ] Работает на desktop, планшетах и мобильных

## **ЭТАП 4: 3D Конструктор (перспектива)** - ⏳ ОТЛОЖЕНО

**Заменяет:** Этап 4 "Продвинутые анимации конструктора"

**Статус:** ⏳ Отложено на перспективу

**Срок:** Будет определён при активации этапа

### Описание

Реализация полноценного 3D конструктора с интерактивной визуализацией будет выполнена при развитии проекта и наличии ресурсов.

### Условия активации

Этап активируется при выполнении ВСЕХ условий:

- [ ] 2D конструктор работает стабильно
- [ ] Есть спрос на 3D визуализацию от пользователей (10%+ запросов)
- [ ] Найдены ресурсы на 3D-моделлинг (100+ компонентов)
- [ ] Производительность 2D версии недостаточна для задач
- [ ] Конкуренты внедрили 3D и это стало стандартом рынка

### Зависимости от Этапа 3

```
Этап 3 (2D) → Архитектура данных → Этап 4 (3D)
              └─ Конфигурация (совместима)
              └─ Совместимость (совместима)
              └─ Расчёт цены (совместим)
              └─ Сохранение/загрузка (совместимо)
              
Этап 4 заменит только визуализацию (2D → 3D),
вся бизнес-логика останется совместимой
```

### План реализации (при активации)

1. **3D моделирование** (4-5 недель)
   - Создание 100+ 3D моделей компонентов
   - LOD уровни детализации
   - PBR материалы

2. **Интеграция Three.js** (3-4 недели)
   - Загрузка .glb/.gltf
   - Орбитальное управление
   - Освещение и тени

3. **Продвинутые анимации** (3-4 недели)
   - Анимации сборки/разборки
   - Физика и столкновения
   - Пост-процессинг

4. **Оптимизация** (2-3 недели)
   - 60 FPS desktop
   - 30+ FPS mobile
   - Инстансинг

**Итого:** 12-16 недель при активации

## Диагностика ошибок TypeScript/JavaScript

### Добавлено в систему тестирования

#### Настройка tsconfig.json

```json
{
  "compilerOptions": {
    "strict": true,
    "noErrorTruncation": true,
    "diagnostics": true,
    "extendedDiagnostics": true
  }
}
```

#### Скрипты

```bash
# Полная проверка TypeScript
npm run type-check:verbose

# Отчёт об ошибках
npm run type-report

# Анализ проекта
npm run analyze
```

#### GitHub Actions

Автоматическая проверка TypeScript при каждом PR:

```yaml
name: TypeScript Diagnostics
on: [push, pull_request]
jobs:
  type-check:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: npm ci
      - run: npx tsc --noEmit --diagnostics
```

#### Runtime сбор ошибок

Автоматический сбор ошибок TypeScript и JavaScript в runtime:

```typescript
// lib/error-collector.ts
window.onerror = (message, source, lineno, colno, error) => {
  errorCollector.collect({
    type: 'runtime',
    message: String(message),
    file: source || 'unknown',
    line: lineno || 0,
    column: colno || 0,
    stack: error?.stack
  });
};
```
