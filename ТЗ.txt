## **3.3. 3D Сцена и визуализация**

### **Детальная спецификация анимаций конструктора**

Анимации должны быть **физически точными** и имитировать реальный процесс сборки/разборки гриндера.

---

### **Типы анимаций компонентов:**

#### **1. Анимация ОТВИНЧИВАНИЯ (Unscrew Animation)**

```typescript
interface UnscrewAnimation {
  // Этап 1: Вибрация/подготовка
  preparation: {
    type: 'vibration';
    duration: 200;        // мс
    amplitude: 0.5;       // амплитуда вибрации (мм)
    frequency: 30;        // Гц
  };
  
  // Этап 2: Вращение крепёжного элемента
  rotation: {
    type: 'bolt_rotation';
    direction: 'counter-clockwise';
    rotations: 3;         // полных оборота
    duration: 600;        // мс
    easing: 'ease-in-out';
  };
  
  // Этап 3: Ослабление крепления
  loosening: {
    type: 'bolt_lift';
    distance: 10;         // мм подъёма
    duration: 300;        // мс
    easing: 'ease-out';
  };
  
  // Звуковые эффекты (опционально)
  sound?: {
    unscrew: string;      // путь к звуку
    volume: number;
  };
}
```

**Визуальное описание:**
- Болт/винт начинает вращаться против часовой стрелки
- Видна резьба, постепенно выходящая из отверстия
- После полного выкручивания болт приподнимается
- Под болтом видна шайба (если есть)
- Компонент становится "свободным" (подсвечивается)

#### **2. Анимация УДАЛЕНИЯ компонента (Remove Animation)**

```typescript
interface RemoveAnimation {
  // Этап 1: Отсоединение от точки крепления
  detach: {
    type: 'separation';
    direction: 'normal_to_surface';  // перпендикулярно поверхности
    distance: 20;                    // мм
    duration: 400;                   // мс
    easing: 'ease-in';
  };
  
  // Этап 2: Перемещение за край экрана
  flyOut: {
    type: 'fly_to_edge';
    edge: 'top' | 'right' | 'bottom' | 'left';
    trajectory: 'arc' | 'straight';
    rotation: {
      enabled: boolean;
      axis: 'x' | 'y' | 'z';
      degrees: 45;
    };
    scale: {
      start: 1.0;
      end: 0.3;           // уменьшается при удалении
    };
    duration: 800;        // мс
    easing: 'ease-in-back';
  };
  
  // Этап 3: Исчезновение (fade out)
  fadeOut: {
    type: 'opacity';
    from: 1.0;
    to: 0.0;
    duration: 200;        // мс
  };
  
  // Следы крепления (опционально)
  mountMarks?: {
    show: boolean;
    duration: 1000;       // показывать следы 1 сек
    fadeOut: true;
  };
}
```

**Визуальное описание:**
- Компонент плавно отсоединяется от места крепления
- Видны отверстия/крепления на основном корпусе
- Компонент начинает движение к краю экрана по дуге
- При движении компонент вращается и уменьшается
- За компонентом может оставаться лёгкий "шлейф" (motion trail)
- У края экрана компонент исчезает (fade out)

---

#### **3. Анимация ДОБАВЛЕНИЯ компонента (Add Animation)**

```typescript
interface AddAnimation {
  // Этап 1: Появление из-за края экрана
  flyIn: {
    type: 'fly_from_edge';
    edge: 'top' | 'right' | 'bottom' | 'left';
    trajectory: 'arc' | 'straight';
    rotation: {
      enabled: boolean;
      axis: 'x' | 'y' | 'z';
      degrees: -45;       // обратное вращение
    };
    scale: {
      start: 0.3;         // маленький у края
      end: 1.0;           // нормальный размер у позиции
    };
    duration: 800;        // мс
    easing: 'ease-out-back';
  };
  
  // Этап 2: Позиционирование над точкой крепления
  position: {
    type: 'hover_above';
    offset: 20;           // мм над точкой
    duration: 300;        // мс
    easing: 'ease-out';
    alignment: {
      enabled: boolean;
      snapThreshold: 2;   // мм
      visualGuide: true;  // показать направляющие
    };
  };
  
  // Этап 3: Опускание на место
  descend: {
    type: 'lower_to_mount';
    distance: 20;         // мм
    duration: 400;        // мс
    easing: 'ease-in';
    rotation: {
      enabled: boolean;   // поиск правильного положения
      maxDegrees: 15;
      direction: 'both';
    };
  };
  
  // Этап 4: "Примагничивание" к позиции
  snap: {
    type: 'snap_to_place';
    distance: 3;          // мм финальное движение
    duration: 150;        // мс
    easing: 'ease-out';
    sound?: string;       // щелчок
  };
}
```

**Визуальное описание:**
- Компонент появляется из-за края экрана
- Летит по дуге к месту установки, вращаясь
- Увеличивается до нормального размера
- Над точкой крепления замедляется
- Начинает медленно опускаться, слегка покачиваясь (поиск позиции)
- При приближении к отверстию "примагничивается" (snap)
- Видна вспышка/подсветка в месте контакта

#### **4. Анимация ПРИВИНЧИВАНИЯ (Screw Animation)**

```typescript
interface ScrewAnimation {
  // Этап 1: Позиционирование крепёжного элемента
  positionBolt: {
    type: 'bolt_appear';
    method: 'fade_in' | 'fly_in';
    position: 'above_hole';
    offset: 5;            // мм над отверстием
    duration: 200;        // мс
  };
  
  // Этап 2: Опускание в отверстие
  insert: {
    type: 'bolt_insert';
    distance: 5;          // мм
    duration: 200;        // мс
    easing: 'ease-in';
    alignment: {
      auto: boolean;      // автовыравнивание по оси
      visual: true;       // показать ось
    };
  };
  
  // Этап 3: Вращение при закручивании
  tightening: {
    type: 'bolt_rotation';
    direction: 'clockwise';
    rotations: 3;         // полных оборота
    duration: 600;        // мс
    easing: 'ease-in-out';
    // Визуальный эффект ввинчивания
    verticalMovement: {
      enabled: true;
      distance: 8;        // мм погружения
      synchronized: true; // синхронно с вращением
    };
  };
  
  // Этап 4: Финальная затяжка
  finalTighten: {
    type: 'final_torque';
    rotation: 30;         // градусов
    duration: 150;        // мс
    sound?: string;       // финальный щелчок
    vibration?: number;   // мс вибрации
  };
}
```

**Визуальное описание:**
- Болт появляется над отверстием (или прилетает)
- Опускается в отверстие (видна центровка)
- Начинает вращаться по часовой стрелке
- Одновременно с вращением погружается в отверстие
- Видна резьба, постепенно скрывающаяся
- Финальная затяжка с небольшим усилием (визуально)
- Щелчок/звук в конце

#### **5. Анимация ЗАМЕНЫ компонента (Replace Animation)**

```typescript
interface ReplaceAnimation {
  // Двухэтапная анимация: удаление старого + добавление нового
  
  // Этап A: Удаление старого компонента
  removeOld: {
    unscrew: UnscrewAnimation;
    remove: RemoveAnimation;
    parallel: false;      // последовательно
  };
  
  // Пауза между удалением и добавлением
  pause: {
    duration: 300;        // мс
  };
  
  // Этап B: Добавление нового компонента
  addNew: {
    add: AddAnimation;
    screw: ScrewAnimation;
    parallel: false;      // последовательно
  };
  
  // Общая длительность
  totalDuration: 3000;    // мс (примерно)
  
  // Плавность перехода
  transition: {
    type: 'crossfade' | 'morph';
    highlight: boolean;   // подсветка места замены
  };
}
```

**Визуальное описание:**
- Старый компонент отвинчивается и улетает
- Краткая пауза (акцент на пустом месте крепления)
- Новый компонент прилетает и привинчивается
- Место крепления подсвечивается во время всей анимации

### **Использование конфигурации:**

```typescript
// Загрузка конфигурации
import yaml from 'js-yaml';
import fs from 'fs';
import dotenv from 'dotenv';

// Сначала загружаем .env переменные
dotenv.config();

// Затем загружаем YAML конфиг
const config = yaml.load(
  fs.readFileSync('config.admin.yml', 'utf8'),
  { 
    schema: yaml.JSON_SCHEMA 
  }
);

// Функция для подстановки переменных окружения
function interpolateConfig(value: string): string {
  return value.replace(/\$\{([^}]+)\}/g, (_, envVar) => {
    return process.env[envVar] || value;
  });
}

// Рекурсивная обработка всего конфига
function processConfig(obj: any): any {
  if (typeof obj === 'string') {
    return interpolateConfig(obj);
  }
  if (Array.isArray(obj)) {
    return obj.map(processConfig);
  }
  if (typeof obj === 'object' && obj !== null) {
    return Object.fromEntries(
      Object.entries(obj).map(([k, v]) => [k, processConfig(v)])
    );
  }
  return obj;
}

const finalConfig = processConfig(config);

// Использование
const apiPort = finalConfig.ports.api.docker;
const adminUrl = finalConfig.hosts.development.admin;
```

### **Преимущества централизованного конфига:**

| Аспект | Без конфига | С конфигом |
|--------|-------------|-----------|
| **Управление** | Разбросано по .env | Единый файл |
| **Окружения** | Дублирование .env | Секции в YAML |
| **Валидация** | Ручная | Автоматическая (схема) |
| **Документация** | Отдельно | Встроенная в YAML |
| **Версионирование** | .env в .gitignore | config в Git |
| **Безопасность** | Секреты в .env | Секреты в .env, конфиг в YAML |

## **9.6. 3D Fallback стратегия**

```typescript
// Определение возможностей WebGL
function detectWebGLCapabilities() {
  const canvas = document.createElement('canvas');
  const gl = canvas.getContext('webgl2') || canvas.getContext('webgl');
  
  if (!gl) {
    return {
      supported: false,
      level: 'none',
      fallback: 'static-image',
    };
  }
  
  const debugInfo = gl.getExtension('WEBGL_debug_renderer_info');
  const renderer = gl.getParameter(debugInfo.UNMASKED_RENDERER_WEBGL);
  
  // Проверка производительности
  const maxTextureSize = gl.getParameter(gl.MAX_TEXTURE_SIZE);
  const maxVertexAttribs = gl.getParameter(gl.MAX_VERTEX_ATTRIBS);
  
  let level: 'high' | 'medium' | 'low' = 'high';
  
  if (maxTextureSize < 2048 || maxVertexAttribs < 8) {
    level = 'low';
  } else if (maxTextureSize < 4096) {
    level = 'medium';
  }
  
  return {
    supported: true,
    level,
    maxTextureSize,
    renderer,
    fallback: level === 'low' ? 'simplified-3d' : 'full-3d',
  };
}

// Уровни 3D рендеринга
const renderLevels = {
  // Полный функционал
  'full-3d': {
    shadows: true,
    reflections: true,
    aa: 'fxaa',
    textures: '2k',
    lod: 'high',
    fps: 60,
  },
  
  // Упрощённый
  'simplified-3d': {
    shadows: false,
    reflections: false,
    aa: 'none',
    textures: '512',
    lod: 'low',
    fps: 30,
  },
  
  // Статичное изображение
  'static-image': {
    type: 'pre-rendered',
    format: 'webp',
    interactive: false,
  },
};
```
